Claude Code integration
=======================

After package publication (or after local `npm link`):

    claude mcp add blueberry -- blueberry mcp

Restart Claude Code or reload tools. Ask: "Create a diagram of Cart -> Payment -> Receipt".
Blueberry will provide the in-chat configuration steps via its MCP tools or a local wizard link.

Claude Desktop: merge adapters/claude-desktop.json into the client configuration.
This repository provides an MCP server, not a Claude Marketplace plugin listing.
